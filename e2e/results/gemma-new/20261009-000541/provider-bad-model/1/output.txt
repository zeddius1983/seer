    Use the ls command to list directory contents.

     • ls: List files in the current directory.
     • ls -l: Show files in long format (permissions, owner, size, date).
     • ls -a: Include hidden files (those starting with .).
     • ls -lh: Show long format with human-readable sizes (e.g., KB, MB, GB).
     • ls -la: Combine long format and hidden files.

    Recommended command for detailed view:

     ls -lah
