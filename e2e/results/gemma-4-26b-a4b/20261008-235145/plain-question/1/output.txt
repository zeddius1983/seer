    Use the find command with the -size flag.

     • Search current directory for files larger than 100MB:

        find . -size +100M

     • Search with file details (size, date, permissions):

        find . -size +100M -exec ls -lh {} +

     • Search a specific path (e.g., /var/log):

        find /var/log -size +100M
