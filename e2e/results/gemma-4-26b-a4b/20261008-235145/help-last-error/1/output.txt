    Your local main branch is behind the remote main branch, meaning there are
    commits on GitHub that you do not have locally.

    Run git pull origin main to integrate remote changes before pushing.

    Recommended Fix

    To maintain a clean history, use rebase:

     • git pull --rebase origin main
     • git push origin main

    Standard Fix

    If you prefer a merge commit:

     • git pull origin main
     • git push origin main

    Destructive Fix

    Only use this if you want to overwrite the remote repository with your local
    state, effectively deleting remote commits:

     • git push origin main --force
